# .NET 8 + React Dashboard

## Dashboard Fullstack con Autenticación JWT, PostgreSQL y Docker

### Características

- Autenticación JWT
- Dashboard con métricas en tiempo real
- PostgreSQL como base de datos
- Docker para contenerización
- GitHub Actions para CI/CD

### Tecnologías

**Backend:**
- .NET 8
- Entity Framework Core
- JWT Authentication
- PostgreSQL

**Frontend:**
- React 18
- TypeScript
- Axios
